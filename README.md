# Payso Remittance UI

A remittance ui exploration dashboard and mobile UI design showcase built with the Next.js App Router.

## Technology stack

- Next.js and React
- TypeScript
- Tailwind CSS
- Swiper
- Next Image
- Iconify

## Setup and commands

```bash
npm install
npm run dev
npm run lint
npm run typecheck
npm run build
npm run verify
```
